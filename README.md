# Employee Salary & Workforce Analysis

## 📌 Project Overview

This project analyzes employee salary and workforce data to identify patterns in salary distribution, departmental payroll, employee distribution, and workforce characteristics.

The analysis was performed using **Python, Pandas, and Matplotlib**, with Excel also used for data analysis and comparison.

The goal is to demonstrate how data analysis can be used to generate insights that support business and workforce decisions.

---

## 🎯 Objectives

The main objectives of this project were to:

- Analyze employee salary patterns
- Calculate average, minimum, and maximum salaries
- Compare salaries across departments
- Calculate total payroll by department
- Analyze employee distribution across departments
- Examine employee age
- Identify employees earning above a specified salary threshold
- Visualize important findings
- Develop data-driven recommendations

## 📊 Dataset

The dataset contains **15 employees** and **4 variables**:

| Column | Description |
|---|---|
| Name | Employee name |
| Department | Employee's department |
| Salary | Employee salary |
| Age | Employee age |

### 1. Data Inspection

The dataset was examined using:

- Dataset dimensions
- Data types
- Summary statistics
- Missing-value checks

### 2. Salary Analysis

The analysis calculated:

## 📈 Key Findings

### Average Salary by Department

| Department | Average Salary |
|---|---:|
| Finance | ₦68,666.67 |
| HR | ₦55,000.00 |
| IT | ₦77,400.00 |
| Sales | ₦58,500.00 |

### Total Payroll by Department

| Department | Total Salary |
|---|---:|
| Finance | ₦206,000 |
| HR | ₦165,000 |
| IT | ₦387,000 |
| Sales | ₦234,000 |

### Overall Findings

- The overall average employee salary was approximately **₦66,133**.
- **IT had the highest average salary** at approximately ₦77,400.
- **HR had the lowest average salary** at ₦55,000.
- **IT had the highest total payroll** at ₦387,000.
- The minimum salary in the dataset was **₦45,000**.
- The maximum salary in the dataset was **₦83,000**.

## 💡 Recommendations

Based on the analysis:

1. Management should review salary differences between departments to ensure that compensation reflects responsibilities, experience, and performance.

2. The relatively lower average salary in HR should be reviewed to determine whether the difference is justified by role requirements and experience levels.

3. Since IT accounts for the highest departmental payroll and average salary, management should continue monitoring IT staffing and compensation costs.

4. Salary decisions should be supported by factors such as employee performance, experience, responsibilities, and market salary benchmarks rather than department alone.

5. Regular workforce and salary analysis should be conducted to help management monitor compensation and staffing trends.
